Shape 1 · effective count

Hill q=0 — coverage / richness / variety

"How many options appeared at all?"

Computed
Count the options with at least one item. Nothing more.
Range
0 to the number of options on the axis.
Blind spot
An option seen twice counts the same as one seen 149 times.
Bad value
Below the option count — an option never appeared, which is a stated coverage gap.
Code
len(counts) in hill.py:54. The "other" escape is excluded, so unclassified items cannot inflate it.

Shape 1 · effective count

Hill q=1 — effective number / balance

"This axis behaves like N evenly used options."

Computed
Shannon entropy of the distribution, then exp(). The exponential puts the answer back into units of categories; raw entropy is in nats and reads as nothing.
Range
1.0 (one option takes everything) to k (k options used evenly).
Read with
Always beside coverage. The gap between the two is the information.
Bad value
Far below coverage. Measured example: standing, coverage 4, effective 2.01 — all four appear, two are decoration.
Code
effective_number(), hill.py:25. Self-check anchors: one category → 1.0, four even → 4.0.

Shape 1 · effective count

Evenness

"What fraction of what this axis could carry does it actually carry?"

Computed
effective ÷ coverage.
Why it exists
A 4-option axis can never score above 4. Evenness lets you compare it against a 6-option axis.
Measured today
beneficiary 0.70 · institution 0.68 · standing 0.50.

Shape 1 · effective count · no code

Vendi Score — semantic diversity

"This corpus of 300 items is about as diverse as N genuinely distinct items."

Computed
Embed every item → build the pairwise similarity matrix → take its eigenvalues → exp(entropy) of them.
The connection
Identical arithmetic to Hill q=1, run on a similarity matrix instead of on category counts. Hill needs labels; Vendi does not. Hill asks "are my labels spread", Vendi asks "is my text spread".
Range
1 (all items near-identical) to n (all mutually unrelated).
Requirement
Compare against a baseline corpus at matched N — the score is not comparable across sample sizes.
Source
Friedman & Dieng, arXiv:2210.02410.

Shape 2 · chance-corrected agreement

Cohen's κ — the gate

"Of the agreement chance did not already hand you, how much did the raters earn?"

Computed
κ = (po − pe) / (1 − pe). po = how often they matched. pe = how often they would match if each kept their own label frequencies but ignored the email.
Run per
Axis, author vs author. Three numbers: beneficiary, institution, standing. Never pooled — a menu defect lives in one axis, and the gate is per facet.
Also computed, never gating
The sentence κ (all three axes as one label, 120 cells) tracks the weakest axis and reads low by construction. Declared in advance so a reviewer does not read it as the headline. Judge-vs-author κ is reported too; author-vs-author is its ceiling.
Bad value
< 0.67. First suspect is the menu, not the raters — check the confusion pairs before anything else.
Code
cohen_kappa(), kappa.py:30. Axis loop at line 76.

Shape 2 · chance-corrected agreement

PABAK — prevalence-adjusted, bias-adjusted κ

"What κ would be if the options were evenly spread."

Computed
2·po − 1. That is the whole formula — raw agreement rescaled onto −1…1.
Why it is reported
The prevalence paradox: when one option dominates, pe rises, 1 − pe shrinks, and κ collapses at unchanged raw agreement. A gap between PABAK and κ tells the reader how much of a low κ is skew rather than sloppiness.
Never
The gate. It is a diagnostic. Gating on PABAK would reward a skewed axis.
Source
Byrt, Bishop & Carlin, PubMed 8501467.

Shape 2 · chance-corrected agreement

Krippendorff's α

"Same job as κ, with a different model of chance."

Computed
1 − Do/De: observed disagreement over expected disagreement. It pools both raters' labels to estimate chance; κ models each rater separately.
Why both
α is the convention NLP annotation reviewers expect, and it extends to more than two raters. κ and α agreeing is quiet evidence the number is not an artefact of one chance model.
Cutoffs
≥ 0.800 reliable · 0.667–0.800 tentative only. Same bars as the κ gate, by design.
Code
krippendorff_alpha(), kappa.py:43 — nominal, two raters, no missing data.

Shape 3 · closeness

Cosine similarity — the near-duplicate check

"Do these two seeds point in the same direction in meaning-space?"

Computed
Dot product of two embeddings, divided by both lengths. That division discards length, so it measures what the text is about, never how much text there is. A 400-word and a 90-word seed on the same situation still score near 1.0.
Run over
WORLD + FACT lines only, not the whole seed. Two seeds may share a writing style; they must not share a situation and a hidden fact.
Threshold
0.90. Strict-sounding but not strict — same-domain English prose already scores high. Calibrated to this corpus and text-embedding-3-small, not a universal duplicate line.
Action on a hit
The later seed regenerates, with its neighbour handed to the model as an explicit negative example. Rewrite, never delete.
Code
_cosine() seedgen.py:679 · _world_fact() :670 · distinct() :719. O(n²) pure Python, minutes at 1200 seeds.

Shape 3 · closeness

Confusion pair share — the shape of disagreement

"Is this disagreement scattered noise, or the same two options over and over?"

Computed
For each disagreed item, record the ordered pair (what A said, what B said) — (practice, provider) ≠ (provider, practice). Count each pair, divide by total disagreements on that axis.
Reading
Scattered thinly over many pairs → noise, which is exactly what κ absorbs. One pair at ≥ 30% → structure: two specific options can both be true, so the menu is still broken.
Why it matters
κ tells you how much they disagreed and nothing about where. This is the automated form of the hand-analysis that killed the flat-13 role list.
Discipline
The 30% line is declared before the run, which is what stops it being a number picked after seeing the data.
Code
confusion() kappa.py:99; share at line 138; OVERLAP_SHARE at line 27.

Shape 3 · closeness · no code

Self-BLEU — lexical diversity

"Do my scenarios recycle each other's phrases?"

Computed
Score each item with BLEU against all the others as references; average. BLEU counts shared word runs (n-grams).
Direction
Lower is more diverse. High Self-BLEU means the corpus repeats itself.
Blind spot
Meaning. Two items about entirely different disasters, written from one template, both score high.
Confound
Length. Compare only at matched N and matched length (arXiv:2507.15092).
Source
Zhu et al., Texygen, arXiv:1802.01886.

Shape 3 · closeness · no code

POS compression ratio — syntactic diversity

"Do my scenarios share one sentence architecture?"

Computed
Replace every word with its part-of-speech tag (DET NOUN VERB ADP DET ADJ NOUN), compress that stream with gzip, take original size ÷ compressed size.
Why compression
Compression is a repetition detector. A corpus built on one grammatical skeleton produces a highly repetitive tag stream, so it compresses well.
Direction
Higher ratio = less diverse.
What it catches that Self-BLEU cannot
Template reuse with every noun swapped. The words differ; the skeleton does not.
Source
Shaib et al., arXiv:2403.00553, diversity package.

Shape 3 · closeness · no code

Cramér's V — facet independence

"Is 14 domains × 5 beneficiaries really 70 kinds of scenario, or 14 wearing two names?"

Computed
From chi-squared on the cross-tabulation of two categorical facets: V = √(χ² / (n · min(r−1, c−1))).
Range
0 = knowing one facet tells you nothing about the other. 1 = it tells you everything.
Why the paper needs it
The diversity claim quietly multiplies facets. That multiplication is only valid if the facets vary independently. If every medical item has a dependent beneficiary and every finance item is myself, the coverage claim is double-counted.
Bad value
High V between two claimed facets. Without this number, a reviewer can ask the question and the paper cannot answer.
Reported as
A pairwise matrix over the facets, beside the coverage tables.

The wobble

95% confidence interval

A claim about the procedure, not about this one interval.

Correct
If you repeated the whole study many times, 95% of the intervals produced would contain the true value.
Wrong, and commonly written
"There is a 95% probability the true κ is in [0.76, 0.86]." The true κ is fixed — it is in there or it is not. The randomness is in which sample you drew.
Consequence for prose
You may write "the procedure has 95% coverage". Do not write "we are 95% confident the true value exceeds 0.80".
Safe working intuition
The width is your instrument's resolution. A wide interval does not mean the estimate is wrong; it means you cannot separate it from nearby values — including the gate.
Policy here
Gate on the point estimate, report the interval. Pre-declared, so the straddle case is decided before you know which side you land on.

The wobble

Percentile bootstrap

"Manufacture the repeated studies you cannot afford to run."

Procedure
(1) Draw n items from your own n, with replacement — some repeat, about a third never appear. (2) Recompute the statistic. (3) Repeat 2000 times. (4) Sort, cut the lowest and highest 2.5%. What remains is the interval.
Reproducible
Seeded with random.Random(0), so nobody can re-roll a number they dislike.
The cluster twist
When rows are correlated — three responses graded on one screen are one joint judgment — resample the item and take all its rows. Resampling rows separately reports a falsely narrow interval, which is an overclaim that looks like rigour. The self-check at kappa.py:166 asserts the clustered interval is wider.
Caveat
Coverage is asymptotic. Fine at n = 300 (≈ ±0.05 at κ = 0.8). At n = 26 it is indicative only — never quote a pilot interval as a result.

kappa_ci(), kappa.py:53. BOOTSTRAP = 2000 at line 26.

Six habits that make a result hard to argue with

  1. Declare every threshold before the run. A bar chosen after the data is not a bar.
  2. Gate on the point estimate, report the interval. Decide the straddle case in advance.
  3. Name the number that is not the headline. The sentence κ reads low by construction — say so first.
  4. Match the resample unit to the judgment unit. Correlated rows resampled as independent overclaim precision.
  5. Report the shape, not only the size. κ + PABAK + α + distribution + confusion pairs lets a reader diagnose a low number.
  6. State what you did not measure. A declared gap is a limitation; a discovered gap is a credibility problem.

None of these makes a number look better. Every one makes it harder to attack.
